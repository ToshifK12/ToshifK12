# About Me

Computer Science senior at **Minot State University**, graduating **May 2027**.

Currently building a **grant-funded Residence Life Duty Log platform** for Minot State University using **Next.js, TypeScript, Supabase, PostgreSQL, and Vercel**.

Interested in **backend engineering, distributed systems, full-stack development, and applied AI**.

Currently focused on improving my skills in **data structures and algorithms, distributed systems, scalable backend architecture, and cloud engineering**.

Open to collaborating on **backend systems, distributed applications, developer tools, and AI-powered products**.

Ask me about **Java, Python, Go, Spring Boot, FastAPI, Next.js, PostgreSQL, Redis, gRPC, REST APIs, RAG systems, and distributed systems**.

### Distributed Key-Value Store
**Go | gRPC | Raft**

- Built leader election, log replication, and write-ahead-log crash recovery
- Tested on a **5-node cluster**
- Achieved **zero data loss across 3,286 writes and 4 random node failures**

- Added per-user session isolation
